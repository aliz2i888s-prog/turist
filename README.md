# TravelWorld — Сайт туристического агентства

Адаптивный лендинг для туристического агентства индивидуального туризма.

## Структура проекта

```
turist-redesign/
├── index.html          # Главная страница
├── css/
│   └── style.css       # Стили
├── js/
│   └── main.js         # Интерактивность
└── assets/
    ├── expeditions.jpg
    ├── guides.jpg
    └── hotels.jpg
```

## Разделы сайта

- **Hero** — главный экран с анимированным фоном и статистикой
- **О компании** — описание агентства с преимуществами
- **Услуги** — 3 карточки с описаниями, ценами и модальными окнами
- **Популярные туры** — 4 готовых маршрута с ценами и кнопками бронирования
- **Отзывы** — 3 отзыва клиентов с рейтингом 4.9
- **FAQ** — 5 часто задаваемых вопросов (аккордеон)
- **Контакты** — форма заявки + контактная информация
- **Футер** — навигация и реквизиты

## Функциональность

- Адаптивный дизайн (Desktop / Tablet / Mobile)
- Мобильное меню (burger)
- Плавная прокрутка к разделам
- Модальные окна для услуг
- FAQ-аккордеон
- Форма заявки с валидацией
- Анимации при скролле (Intersection Observer)
- Кастомный курсор
- Lightbox для изображений
- Sticky header

## Технологии

- HTML5, CSS3, Vanilla JavaScript
- Google Fonts (Cormorant Garamond + DM Sans)
- CSS Variables, Grid, Flexbox
- CSS Animations & Transitions

## Запуск

Открыть `index.html` в браузере или запустить через Live Server.
